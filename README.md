# papamarathon

A cinematic personal marathon journey archive for Deepesh, built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Supabase.

## Development

```bash
npm install
npm run dev
```

Supabase values belong in a local `.env` file using `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`. The public experience includes a local fallback archive when Supabase is not configured.
